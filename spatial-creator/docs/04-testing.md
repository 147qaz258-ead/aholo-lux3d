# 04 · 测试记录

原则：**不用 mock 替代真实链路**。三维几何、手势状态、Lux3D 调用都必须跑真东西，测试只负责断言和截图。

## 如何复现

```bash
# 前置：API 与前端都要在跑
npm run dev:api         # :8787
npm run dev             # :5173

# 1) 交互验收（5 项，约 40 秒）
node scripts/test-interaction.mjs

# 2) 真实 Lux3D 端到端（约 5–6 分钟，消耗积分）
node scripts/e2e-lux3d.mjs 8790

# 3) 真实模型载入 + 高面数雕刻 + 截图（约 40 秒）
node scripts/smoke.mjs

# 4) AI 全链路 UI（真实点击提交，约 5–6 分钟，消耗积分）
node scripts/test-ai-flow.mjs

# 5) 图生 3D 上传链路（零积分）
node scripts/test-img-to-3d.mjs
#    完整图生任务（消耗 1 次生成额度）
node scripts/test-img-to-3d.mjs test-artifacts/22-model.png --full

# 6) 刷新恢复 + 权限拒绝降级（约 60 秒，必须打 :5173）
node scripts/test-acceptance-gaps.mjs

# 7) 图生模型入场景 + 雕刻（约 40 秒，必须打 :5173）
node scripts/test-img2model-load.mjs
```

脚本使用系统 Chrome（`channel: "chrome"`），假摄像头用 `--use-fake-device-for-media-stream`。
