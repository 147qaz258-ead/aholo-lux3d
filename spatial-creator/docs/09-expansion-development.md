检查器内容可向下滚动。创建一个立方体后，可以立即试用多选、材质、视图和本地指令；不需要先连接 AI 服务。

指令示例：

- `把它缩小10%`：生成缩放预览。
- `把「立方体」向右移动0.2`：精确绑定唯一名称。
- `把刚才那个改为蓝色`：引用最近接受的对象，即使当前选择已改变。
- `解释场景`：根据当前对象、可见性、锁定和连接状态给出统计，不修改作品。

目标包含子对象时，本地单对象变换指令拒绝；使用整体选择变换。锁定对象不能修改。自由自然语言、组合指令和未支持动作不会隐式转为生成请求。

## 保存与交换边界

- 自动保存、50 步会话撤销、最近有效快照恢复沿用首轮实现。
- 原生 `.aether.json` 包含当前对象/材质/纹理/资产/关系/关节限位/视图/任务/参考图；命名版本列表只在此浏览器保存，不随原生文件打包。
- 删除资产库条目保留底层数据，以支持撤销和历史版本；尚无自动垃圾回收，长时间使用会累积存储。
- 导入仍归一化为 1.2 场景单位；不保留制造单位。OBJ 没有 MTL 配套，OBJ/STL 仅几何；STL 导出不代表可打印性检查完成。
- 滑动关节数值使用世界场景单位；共同等比缩放两个零件时，位移与上下限一起缩放，保持已有约束。装配整体、父级和多选三条变换路径均有回归。
- 模型 60MB / 200 万顶点、工程文件 250MB 是保护阈值，不是经过压力验收的性能上限。

## 手势工作区与听写增量（2026-11-18）

| 规格或需求 | 新增入口 | 验证范围 |
|---|---|---|
| 手部感知 §2、实时直接操控 §8–9 | 三维视口显示两只手。双手捏合编辑物体时，任一参与手丢失即冻结，恢复超时会回滚 | 浏览器合成关键点验证双手批次和辅助手丢失回滚 |
| 场景视图 §4 | 一只张掌拨动相机，双掌开合缩放，同向移动平移。「视图」菜单集中标准视图、投影和定位 | 验证透视旋转、正交缩放与平移、视图保存以及场景历史隔离 |
| 空间绘制 §4–6 | 绘制时靠近起点松手闭合。捏住厚度手柄上下拖动。属性区的「实体厚度」可用于已有笔迹 | 验证轮廓拉伸、源笔迹恢复、封闭网格、工程校验和 GLB 回导 |
| 手势优先工作区 | 握拳呼出工具，剪刀手向左或向右划完成撤销或重做。启动摄像头后默认收起工具栏和属性区 | 验证捏合切换工具和撤销重做。鼠标可通过顶栏重新展开工具和属性 |
| AI 生成描述听写 | 底部生成框的麦克风按钮启动普通话听写。听写写入草稿，用户确认提交后才启动生成 | 用模拟语音事件验证转写、停止、取消、权限拒绝及草稿保留 |

默认参考动作包括约 150 ms 的张掌确认、视口短边 3% 的视角移动死区、约 400 ms 的握拳菜单确认以及约 200 ms 的剪刀手确认。视角转动不进入对象的撤销历史。拉伸保留来源笔迹，创建实体与隐藏来源笔迹合为一步撤销。

浏览器语音识别的支持情况和麦克风权限因运行环境而异。识别不可用时，点击描述框后可按 `Win + H`，或使用键盘输入。

在 1600×900、Intel UHD 核显和单立方体的隔离 Chrome 中，单手、双手合成输入均为约 60 FPS，P95 帧间隔分别为 17.1 和 17.2 ms，总绘制调用均为 17 次。详见 [基准结果](../test-artifacts/performance/gesture-workspace.json)。复现回归使用 `npm run test:workspace`，对照相机路径使用 `node scripts/test-camera-performance.mjs`。

真实摄像头的端到端延迟、物理麦克风的普通话识别、连续手势误触及首次用户任务完成率仍需真机记录。通用多轮语义约束、远程区域生成和复杂装配约束的状态沿用上表。
