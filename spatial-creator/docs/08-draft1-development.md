## 3. 实现参数与支持边界

- 自动保存：700ms 防抖，较规格建议 5 秒更积极，待按存储性能调参。保存等事务成功才报告完成；current/backup 原子写入。损坏数据阻止自动覆盖并保留诊断副本；恢复前等待在途保存。
- 历史：50 个场景快照，新编辑清空 redo。只在当前会话保留。资产为撤销保留，尚无自动垃圾回收。
- 原生格式：`.aether.json` v2，base64 内嵌模型、重映射资产键；保护上限 250MB，未做此规模压力认证。损坏文件在切换工程前拒绝。
- GLB / 内嵌 glTF：60MB、200 万顶点保护阈值；不支持外置 bin/贴图包。导入明确归一化到 1.2 场景单位，不用于保留制造尺寸。骨骼动画导出拒绝。
- 装配：固定连接，TRS 变换；带子对象只允许等比缩放，拒绝剪切。子对象锁定冻结整体变换。删父对象时保留子对象世界位置，解除直接层级，可撤销。
- AI：现有供应商仅负责整体模型生成。文生保存完整原始提示和实际发送摘要；图生无文字约束。图片本体/哈希和参考用途的完整持久化尚未完成。每任务成本记录 unknown，待供应商可查询成本。
- 幂等缓存：`.runtime/ai-requests.json`，最多 1000 项；未知结果不自动重提。不承诺无限期或跨多实例全局幂等。
- 手势：三帧确认、450ms 回滚为工程候选。形变半径为对象对角线 5%–20%；按压最多最小边 5%，拉伸最多最小边 20%，仍需网格质量和用户测试。
- 当前细曲线以细管网格呈现，以兼容现有拾取/导出；不是完整参数曲线 CAD 内核。关键点回放只用于诊断，不是完整场景命令重演。

## 4. 复现与证据

先 `npm run dev:all`，再执行 `npm run test:draft1`、`node scripts/test-api-local.mjs`、`node scripts/test-production.mjs`；构建为 `npm run build`。Playwright 路径通过 `PW_PATH` 配置，运行细节见根 README。

本轮最终验证：TypeScript 与生产构建通过；浏览器 **24/24** 组、幂等 **4/4** 组、本地 API **5/5** 组、生产包冒烟 **6/6** 组通过。生产包另用独立浏览器检查没有开发调试钩子、通过界面创建/保存对象、帮助弹窗，以及 1280×800 / 1280×720 工具可达性和 390px 项目弹窗。窄屏检查不代表移动端产品认证。构建有混用动态/静态 import 的分包提示，不影响构建结果。

回归环境：本机 Chrome、1600×1000、隔离浏览器上下文，可使用 SwiftShader 软件 WebGL。它验证行为/几何状态，不能代表参考 PC 的 GPU 性能。组数不替代规格要求的真实样本量。
