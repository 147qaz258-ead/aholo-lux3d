## 使用规则

-   Feature Inventory v2 的 270 项只代表现有实现资产，不是产品需求上限。
-   现有实现与新增产品需求必须区分。
-   每项核心功能需要完整定义用户目标、输入、前置条件、处理逻辑、参数、输出、状态、异常、恢复、指标、测试和交付物。
-   数值目标均为初始候选值，必须通过参考设备基线测试和用户测试后冻结。
-   定性体验必须使用标准任务、评分锚点、样本和原始反馈。
-   本套文档不是当前产品已经达标的证明。
