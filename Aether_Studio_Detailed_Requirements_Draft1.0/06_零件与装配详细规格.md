# Aether Studio｜零件与装配详细规格

**文档编号：** AS-FS-ASSEMBLY-001\
**版本：** Draft 1.0\
**范围：**
独立零件、对象层级、连接点、连接类型、对齐、装配、拆卸、替换、AI
装配协作和装配持久化\
**产品主线：** 将独立三维对象组织为可持续编辑的结构化装配体

------------------------------------------------------------------------

## 1. 产品目标与范围

Aether Studio 不应只把场景理解为一组互不关联的
Mesh。用户需要能够将复杂模型拆分为独立零件，建立零件之间的连接关系，单独修改零件，并在替换或移动零件时保持装配关系可预测。

本规格中的"装配"首先定义为**三维创作中的结构化零件装配**，不是完整机械
CAD 求解器，也不承诺 V1 具备有限元、动力学或制造级约束求解。

### 1.1 V1 能力范围

P0： - 对象定义为独立零件。 - 零件唯一身份。 - 零件层级和父子关系。 -
固定连接关系。 - 连接点定义和对齐。 - 装配体整体移动、旋转和缩放。 -
零件独立编辑。 - 拆卸和替换。 - 保存与恢复装配关系。

P1： - 旋转铰接关系。 - 直线滑动关系。 - 多连接点装配。 - AI
根据装配上下文生成缺失零件。 - 装配检查和冲突提示。

P2： - 更复杂的机械约束。 - 运动范围和机构联动。 -
物理仿真和工程级装配分析。

## 2. 核心数据对象

### 2.1 Part

每个独立零件必须具有稳定身份：

``` ts
type Part = {
  partId: string;
  objectId: string;
  name: string;
  geometryRef: string;
  materialRefs: string[];
  localTransform: Transform;
  parentAssemblyId?: string;
  source: "manual" | "ai" | "import" | "converted";
  version: number;
  locked: boolean;
  visible: boolean;
};
```

### 2.2 Assembly

装配体是一个逻辑容器，不应简单合并所有 Mesh 后丢失零件身份。

``` ts
type Assembly = {
  assemblyId: string;
  name: string;
  rootPartId: string;
  partIds: string[];
  relationIds: string[];
  transform: Transform;
  version: number;
};
```

### 2.3 Connector

连接点定义零件之间的局部连接坐标：

``` ts
type Connector = {
  connectorId: string;
  partId: string;
  localPosition: [number, number, number];
  localRotation: [number, number, number];
  axis: [number, number, number];
  connectorType: "fixed" | "revolute" | "slider";
};
```

### 2.4 AssemblyRelation

``` ts
type AssemblyRelation = {
  relationId: string;
  parentPartId: string;
  childPartId: string;
  parentConnectorId: string;
  childConnectorId: string;
  relationType: "fixed" | "revolute" | "slider";
  parameters: Record<string, number>;
  status: "valid" | "broken" | "suppressed";
};
```

字段可以与项目现有场景数据模型统一，但必须保留零件 ID、连接 ID
和版本信息。

## 3. 零件创建与识别

### 3.1 从对象创建零件

用户可以将一个现有场景对象转换为独立零件。

行为： 1. 用户选择对象。 2. 点击"转换为零件"。 3. 系统创建 Part ID。 4.
保留对象几何、材质和 transform。 5. 在零件列表中显示。 6.
原对象不应被重复复制或丢失。

验收： - 转换成功率 100%（支持对象类型）。 -
转换前后几何顶点数量和位置保持一致。 - 对象 ID 与 Part ID 的关联唯一。 -
100 次转换测试无对象丢失或重复。

### 3.2 零件命名

-   默认名称采用类型 + 序号。
-   用户可以修改名称。
-   同一装配体内名称允许重复，但 Part ID 必须唯一。
-   重命名不得改变 Part ID 或连接关系。
-   保存恢复后名称保持一致。

## 4. 零件层级

### 4.1 父子关系

父对象变换时，子对象按局部 transform 继承变换。

要求： - 父级变换不改变子对象的局部 transform。 -
子对象单独移动时，更新其局部 transform。 -
删除父对象前必须明确处理子对象：一并删除、解除父子关系或取消操作。 -
不允许静默删除子零件。

### 4.2 层级深度

V1 初始支持至少 5 层层级深度，单个装配体至少 100
个零件条目（性能需在参考 PC 测试）。

验收： - 5 层父子关系变换正确。 - 100 个零件列表滚动和选择无阻断。 -
展开/折叠不改变场景数据。 - 层级循环引用必须拒绝。

## 5. 连接点定义

### 5.1 连接点创建

用户可以在零件表面或局部坐标系中创建连接点。

连接点至少包括： - 所属 Part ID。 - 局部位置。 - 局部朝向。 -
主连接轴。 - 连接类型。 - 可选连接名称。

### 5.2 连接点可视化

-   连接点显示为可见标记。
-   选中连接点时显示方向轴。
-   连接点隐藏/显示不影响实际连接数据。
-   连接点必须随所属零件 transform 变化。

验收： - 连接点世界坐标与零件局部坐标变换一致。 -
零件移动后连接点显示偏差 ≤零件包围盒对角线的 0.1%。 - 连接点方向误差
≤1°（测试模型和固定变换条件）。

## 6. 固定连接（P0）

### 6.1 用户操作

1.  选择第一个零件。
2.  选择其连接点 A。
3.  选择第二个零件。
4.  选择其连接点 B。
5.  系统预览对齐结果。
6.  用户确认连接。
7.  系统创建固定关系。
8.  两个零件成为同一装配体的一部分。

### 6.2 对齐计算

连接后，两个连接坐标系必须重合： - 连接点位置重合。 -
连接主轴方向按定义对齐。 - 连接旋转方向按连接类型规则确定。

系统不得在预览阶段直接修改正式对象
transform。只有用户接受后才提交装配关系。

### 6.3 固定连接验收

  -------------------------------------------------------------------------
  指标                                      初始目标 测量
  --------------------- ---------------------------- ----------------------
  连接位置误差            ≤装配体包围盒对角线的 0.5% 两连接点世界坐标距离

  连接轴角度误差                                 ≤1° 两轴夹角

  连接创建成功率                             ≥95/100 标准连接点测试

  连接后相对漂移                       0（静态测试） 移动装配体 100
                                                     次后检查相对 transform

  拆卸后零件保留率                              100% 拆卸后检查 Part ID
                                                     和几何

  保存恢复关系完整率                            100% 保存、关闭、重新打开
  -------------------------------------------------------------------------

## 7. 旋转铰接与滑动连接（P1）

### 7.1 Revolute Joint

允许子零件围绕指定连接轴旋转。

必须定义： - 旋转轴。 - 零角度基准。 - 最小角度。 - 最大角度。 -
当前角度。 - 是否允许越过角度边界。

初始默认范围可设置为 -90° 至 +90°，但具体产品默认值应由用户任务决定。

验收： - 旋转轴方向误差 ≤1°。 - 角度输入误差 ≤1°。 -
超出范围时必须限幅。 - 旋转时连接点位置偏差 ≤装配体包围盒对角线的 0.5%。

### 7.2 Slider Joint

允许子零件沿指定轴平移。

必须定义： - 滑动轴。 - 初始位置。 - 最小位移。 - 最大位移。 -
当前位移。

验收： - 滑动轴偏差 ≤1°。 - 位移误差 ≤目标行程的 1%。 - 越界时限幅。 -
连接点横向偏移 ≤装配体包围盒对角线的 0.5%。

### 7.3 V1 边界

V1 不应宣称支持完整物理机构仿真。Revolute 和 Slider
仅定义几何约束关系和交互变换，不自动模拟重力、惯性、摩擦或电机动力学。

## 8. 装配体操作

### 8.1 整体变换

用户选中 Assembly 后，可整体移动、旋转和缩放。

要求： - 零件之间的相对 transform 保持。 - 整体缩放不得破坏连接关系。 -
子零件单独锁定时，是否允许整体变换必须有明确策略。 -
整体操作提交为一个历史步骤。

验收： - 100 次整体变换后，相对位置误差 ≤包围盒对角线 0.1%。 -
相对旋转误差 ≤0.5°。 - Undo 后整个装配体恢复到操作前状态。

### 8.2 零件独立编辑

-   用户可以在装配体中选择单个零件。
-   编辑单个零件时，其他零件不发生非预期变化。
-   若编辑导致连接点错位，显示关系破坏提示。
-   用户可以接受"解除/破坏连接"，也可以取消编辑。

验收： - 100 次局部编辑中，未选择零件的几何和 transform 不变。 -
连接关系破坏必须被检测。 - 不允许静默保留失效连接状态。

## 9. 拆卸与替换

### 9.1 拆卸

-   用户选择连接关系。
-   系统高亮两个连接零件。
-   用户确认拆卸。
-   连接关系状态变为 suppressed 或删除。
-   两个零件仍保留独立 Part ID 和几何。

验收：100 次拆卸后零件数量、ID 和几何完整。

### 9.2 替换零件

-   用户选择装配中的目标零件。
-   选择替换来源（新生成、导入或现有零件）。
-   系统预览尺寸和连接点匹配情况。
-   用户确认后替换。
-   若连接点无法匹配，显示哪些关系会失效。
-   旧零件版本保留，可撤销。

验收： - 替换不影响未关联零件。 - 可匹配连接关系保留率
≥95%（声明支持的替换任务集）。 - 无法匹配关系必须明确标记 broken。 -
Undo 可恢复原零件和关系。

## 10. AI 与装配协作

AI 生成零件时，必须提供： - 目标装配体 ID。 - 邻接零件 ID。 -
连接点和连接轴。 - 可用空间和包围盒。 - 用户指定用途。 -
需要保留的约束。

AI 结果进入场景前必须检查： - 零件 ID 新建。 - 连接点数据完整。 -
与目标装配的尺寸和位置关系可解释。 - 不会未经授权替换已存在零件。

验收： - 20 个固定装配补件任务中，AI 生成结果能被结构解析。 -
生成结果不得修改未授权零件。 - 用户接受前不提交装配关系。 -
用户拒绝后场景不变。 - 生成零件接受后可独立选择和编辑。

## 11. 装配可视化与反馈

必须提供： - 装配体名称。 - 零件数量。 - 零件层级。 - 连接关系状态。 -
当前选中零件。 - 连接点标记。 - 未连接零件状态。 - 失效连接警告。 -
整体/局部选择状态。

用户必须能区分： - 普通对象。 - 独立零件。 - 装配体。 - 已连接零件。 -
未连接零件。 - 失效连接。

## 12. 数据保存与恢复

必须保存： - Assembly ID。 - Part ID。 - 零件层级。 - 每个零件局部
transform。 - 连接点。 - 连接关系类型和参数。 - 关系状态。 -
版本和来源。

验收： - 100 个零件的测试装配体保存恢复后，Part ID、关系数量和局部
transform 100% 一致。 - 不允许因保存/恢复将独立零件合并成一个不可编辑
Mesh。 - 删除或替换零件后的关系状态必须正确恢复。
