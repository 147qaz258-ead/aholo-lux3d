# Aether Studio｜空间绘制与三维编辑详细规格

**文档编号：** AS-FS-DRAW-001\
**版本：** Draft 1.0\
**范围：**
手势绘制、轨迹采样、平滑、独立对象、曲线/管状体转换、闭合面、编辑、对象操作和几何质量\
**对应现有资产：** Inventory C2、C1、C5、C7、D1---D7、G 相关模块

------------------------------------------------------------------------

## 1. 产品目标

用户在三维工作空间中移动手部时，屏幕实时显示对应轨迹。用户结束绘制后，轨迹成为独立场景对象，能够继续选择、移动、编辑、转换、组合、保存，并作为
AI 生成输入。

当前实现记录的绘制平面是相机前方固定距离 3.2 的平面。因此 V1
必须明确区分： - 固定工作平面上的三维场景轨迹。 - 多深度层绘制。 -
任意空间深度的自由三维绘制。

后两项不能因为已有固定平面绘制就视为已经实现。

## 2. 绘制模式与状态

### 2.1 工具进入

-   用户从 ToolRail 选择"绘制"。
-   当前工具状态高亮。
-   屏幕显示当前绘制平面和操作提示。
-   若摄像头或手部追踪不可用，显示原因并禁止起笔。

### 2.2 状态机

``` mermaid
stateDiagram-v2
    [*] --> Idle
    Idle --> Ready: 进入绘制工具
    Ready --> Drawing: 捏合达到启动阈值
    Drawing --> Drawing: 手部移动并采样
    Drawing --> Paused: 手部短暂丢失
    Paused --> Drawing: 追踪恢复且仍在超时范围
    Drawing --> Completed: 正常释放
    Drawing --> Cancelled: 用户取消
    Paused --> Cancelled: 超过丢失超时
    Completed --> EditableStroke: 生成几何对象
    EditableStroke --> Ready
    Cancelled --> Ready
```

### 2.3 起笔条件

必须满足： - 当前工具为绘制。 - 手部追踪有效。 - 输入未被 UI 消费。 -
捏合状态从 Open 转为 Pressed。 - 当前绘制平面有效。 - 没有未结束笔迹。

起笔时记录： - strokeId。 - startTime。 - activePlaneId。 -
cameraTransform。 - initialPointerWorld。 - brush settings。 - input
source。 - application build。

## 3. 绘制平面

### 3.1 V1 固定平面

现有实现记录 `DRAW_DISTANCE = 3.2`。该值属于当前场景坐标系中的距离参数。

要求： - 绘制开始时确定平面。 - 一次笔迹期间平面不随手部深度估计抖动。 -
相机发生变化时，不得让正在绘制的轨迹产生坐标跳变。 -
结束后将轨迹点转换为场景世界坐标。 -
绘制平面应可视化，或通过清晰反馈让用户理解当前绘制深度。

### 3.2 多平面拓展

若支持多层绘制： - 用户必须明确选择当前平面。 -
当前平面名称/深度层可见。 - 平面切换只能在没有活动笔迹时执行。 -
已完成笔迹不因当前平面变化而移动。 - 不同平面之间应有视觉区分。

初始探索性配置可采用 3
个深度层（近、中、远），但实际层数和间距应通过用户任务测试确定，不作为当前已实现能力。

## 4. 轨迹采样

### 4.1 采样输入

每个有效采样点包含： - timestamp。 - pointer screen position。 - world
position。 - active plane ID。 - pinch state。 - tracking validity。

### 4.2 距离采样

当前实现记录点距阈值 0.012
场景单位。产品验收不能只看该常量，必须看轨迹质量。

建议保留距离阈值作为最小采样间隔，同时增加最大时间间隔保护： -
当相邻点距离 \<0.012 且时间间隔 \<50ms，可跳过。 - 当相邻点距离
≥0.012，记录新点。 - 当移动速度较高且距离阈值未达到，但时间间隔
≥50ms，仍记录点，避免高速移动出现断线。

上述 50ms 是初始工程目标，需通过高速轨迹测试校准。

### 4.3 点数上限

当前实现单条笔迹最多 420 点。产品规格要求： - 达到 420
点时不得静默丢弃后续轨迹。 -
应提示达到当前笔迹复杂度上限，或执行有质量约束的简化。 -
若简化，必须保留端点和主要转折点。 - 简化前后轨迹 RMS 偏差目标
≤原轨迹包围盒对角线的 1%。

## 5. 轨迹平滑

### 5.1 目标

去除手部追踪噪声，但不能过度平滑导致用户画出的拐角、轮廓和细节消失。

### 5.2 要求

-   原始采样点必须保留，平滑结果作为独立输出。
-   平滑强度可调。
-   直线不应产生不必要弯曲。
-   圆弧应保持曲率连续。
-   折线应保留主要转折点。
-   轨迹首尾位置不得明显漂移。

### 5.3 验收

标准轨迹集： - 水平直线。 - 垂直直线。 - 45° 斜线。 - 圆形。 - 方形。 -
锯齿线。 - S 曲线。 - 闭合不规则轮廓。

初始目标： - 轨迹 RMS 偏差 ≤参考轨迹包围盒对角线 2%。 - 轨迹端点偏差
≤参考轨迹包围盒对角线 1%。 - 主要转折点保留率 ≥95%。 - 轨迹中断率
≤1%。 - 不得因平滑使闭合轮廓变成明显开口。

## 6. 实时预览

当前实现记录 LiveRibbon 预分配缓冲，避免每帧触发 React 更新。

产品要求： - 用户移动手部时，轨迹实时显示。 -
预览轨迹与实际采样点保持一致。 - 不得出现持续积压导致预览明显落后。 -
预览和最终几何对象在位置、方向和形状上保持一致。

初始目标： - 绘制输入到预览更新 P95 ≤100ms。 - 参考 PC
下绘制期间渲染帧率 P95 ≥30 FPS。 - 预览结束到最终对象出现
≤200ms（不含复杂几何异步计算）。

## 7. 结束、取消与生成对象

### 7.1 正常结束

-   捏合释放达到释放阈值并确认后结束。
-   检查轨迹点数和最小长度。
-   执行平滑。
-   构建最终几何。
-   创建独立场景对象。
-   分配唯一 strokeId/objectId。
-   自动命名。
-   提交场景状态和历史记录。

### 7.2 取消

-   用户按 Escape 或点击取消。
-   删除当前未完成预览。
-   不创建场景对象。
-   不产生历史步骤。
-   显示"已取消绘制"。

### 7.3 最小有效轨迹

初始规则： - 至少 3 个有效采样点。 - 总路径长度至少 0.03 场景单位。 -
若不足，提示轨迹太短，不生成对象。

上述阈值需要结合当前场景单位和手部映射实际校准。

## 8. 轨迹对象规格

每条轨迹至少保存： - objectId。 - strokeId。 - rawPoints。 -
smoothedPoints。 - activePlaneId。 - worldTransform。 - radius/width。 -
material/color。 - createdAt。 - source（hand drawing / imported /
AI）。 - geometryType。 - version。

### 8.1 独立对象行为

用户必须能： - 单独选择轨迹。 - 移动轨迹。 - 旋转轨迹。 - 缩放轨迹。 -
修改颜色。 - 修改粗细。 - 隐藏/显示。 - 锁定/解锁。 - 删除。 - 复制。 -
撤销/重做。 - 保存/恢复。

验收： - 轨迹对象在对象列表中有独立条目。 - 100
次对象操作中不影响其他对象。 - 保存恢复后轨迹点数、变换和材质一致。 -
删除只影响目标轨迹。

## 9. 轨迹到几何体的转换

### 9.1 管状体

当前实现记录使用 CatmullRom 管状几何，最多 600 段。

要求： - 半径可配置。 - 段数与路径长度和曲率相关。 -
不能只因达到固定段数而产生明显折角。 - 几何生成后法线正确。 -
生成对象可被选择、移动、雕刻（若对象类型支持）。

初始质量目标： - 管状体中心线与平滑轨迹 RMS 偏差 ≤轨迹包围盒对角线
1%。 - 几何不得出现 NaN/Infinity。 - 闭合曲线连接处不得出现明显断口。 -
生成时间 P95 ≤500ms（参考 PC、420 点以内笔迹）。

### 9.2 曲线对象

拓展要求： - 用户可将笔迹保留为可编辑曲线。 - 曲线控制点可选择和移动。 -
控制点变化后曲线实时更新。 - 可调整曲线平滑程度。 -
可将曲线转换为管状体。

验收： - 控制点编辑后曲线连续。 - 曲线端点与控制点关系可预测。 -
转换前后中心线偏差符合目标。

### 9.3 闭合轮廓与面生成

仅当轨迹形成有效闭合轮廓时允许生成面。

初始闭合判定： - 轨迹首尾距离 ≤包围盒对角线的 2%。 -
闭合后执行自交检查。 - 若存在自交，提示用户修正，不静默生成错误面。

验收： - 有效闭合轮廓生成面成功率 ≥95%。 - 面边界与原始轮廓偏差
≤包围盒对角线 2%。 - 非法自交轮廓拒绝生成并说明原因。

## 10. 草图与 AI 的连接

每条轨迹可以作为 AI 任务输入。必须保留： - 原始轨迹对象 ID。 -
轨迹坐标和工作平面。 - 轨迹变换。 - 用户输入的文本提示。 - 关联生成任务
ID。

AI
不得修改原始草图，除非用户明确选择修改。默认生成结果作为新对象进入场景。

## 12. 用户测试

首轮 8---12 名参与者，每人完成： - 一条直线。 - 一个圆。 - 一个方形。 -
一条锯齿线。 - 一个自由轮廓。 - 一次绘制后移动、改色和删除。 -
一次绘制作为 AI 输入（AI 模块接入后）。

记录： - 首次成功率。 - 完成时间。 - 轨迹误差。 - 重画次数。 -
是否理解当前绘制平面。 - 是否能理解如何结束和取消。 - 手部疲劳评分。

首轮目标： - 80% 参与者无需额外帮助完成基础绘制任务。 - 80%
参与者能够正确解释当前绘制平面。 -
任何因绘制结束方式不清楚导致的误操作必须单独修正。
