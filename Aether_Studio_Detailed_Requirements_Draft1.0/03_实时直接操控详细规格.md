# Aether Studio｜实时直接操控详细规格

**文档编号：** AS-FS-MANIP-001\
**版本：** Draft 1.0\
**范围：**
悬停、虚拟接触、捏合抓取、对象移动、局部按压、局部拉伸、双手变换、取消和恢复\
**对应现有资产：** Inventory B、C1、C3、C4、C5、C6、C7、C8

------------------------------------------------------------------------

## 1. 产品目标

用户能够用手部动作直接操控三维对象和对象表面。系统需要让用户明确知道当前目标、当前操作和操作结果，并保证输入到场景变化之间连续、稳定、可恢复。

本系统使用普通 RGB
摄像头，因此"接触"定义为摄像头指针经场景射线命中得到的**虚拟接触**；"按压强度"定义为捏合闭合程度等手势代理量，不代表真实物理力。

## 2. 统一交互坐标和命中

### 2.1 交互输入

-   指针源：食指尖 landmark 8。
-   手势源：归一化 pinchClosure。
-   场景源：当前活动相机和可交互 Mesh。
-   UI 输入优先级：UI 消费输入时，3D 场景不得再次处理。

### 2.2 命中数据

每次有效命中至少记录： - objectId。 - faceIndex。 - pointWorld。 -
normalWorld。 - pointerScreen。 - timestamp。 - toolMode。 -
objectLocked。 - hitValid。

### 2.3 目标锁定

连续操作一旦启动： - 锁定 objectId。 - 锁定起始命中点。 - 锁定起始对象
transform 或几何基准。 - 不允许操作中途自动切换目标。 -
目标被删除或变为不可编辑时，立即安全结束。

## 3. 统一状态机

``` mermaid
stateDiagram-v2
    [*] --> Idle
    Idle --> Tracking: 手部有效
    Tracking --> Hover: 命中可交互目标
    Hover --> Candidate: 满足操作候选条件
    Candidate --> Active: 连续确认
    Candidate --> Hover: 条件不成立
    Active --> Updating: 输入持续变化
    Updating --> Updating: 下一有效输入
    Updating --> ReleasePending: 释放条件成立
    ReleasePending --> Commit: 连续确认释放
    ReleasePending --> Updating: 输入恢复
    Active --> Cancelled: 用户取消
    Updating --> Cancelled: 用户取消
    Active --> Lost: 追踪丢失
    Updating --> Lost: 追踪丢失
    Lost --> Recovering: 手部重新出现
    Recovering --> Updating: 满足恢复条件
    Recovering --> Commit: 超时或不满足恢复条件
    Commit --> Tracking
    Cancelled --> Tracking
```

## 4. 悬停与虚拟接触

### 4.1 悬停

定义：指针射线命中可交互对象，但尚未触发接触或抓取。

行为： - 高亮目标对象。 - 显示对象名称。 - 显示接触点候选位置。 -
不修改几何或对象 transform。

验收： - 命中对象与高亮对象 ID 必须一致。 - 目标切换反馈 P95
≤100ms（本地 UI 反馈候选目标）。 - 稳定指向 10 秒，目标状态误切换 ≤1
次。

### 4.2 虚拟接触

定义：指针射线与目标 Mesh 产生有效交点，并且输入稳定满足接触确认条件。

初始规则： - 连续 3 个有效输入结果命中同一 objectId。 -
命中点屏幕位置变化不超过目标投影宽度的 2%（待校准）。 - 当前输入未被 UI
消费。 - 对象可编辑且未锁定。

接触反馈： - 命中位置出现接触环。 - 对象局部区域显示轻量高亮。 -
接触未确认时不得产生形变。

## 5. 捏合抓取与对象移动

### 5.1 功能目标

用户用食指指向对象并捏合，系统选中并抓取该对象；保持捏合移动手部时，对象按映射规则跟随；松开后对象停止跟随并提交最终
transform。

### 5.2 启动条件

必须同时满足： - 当前工具为选择/抓取。 - 手部追踪有效。 -
射线命中可编辑对象。 - 对象未锁定。 - pinchClosure ≥0.62 连续 3
个有效结果。 - UI 未消费该输入。 - 当前没有其他活动抓取操作。

### 5.3 移动映射

V1 默认使用相机朝向平面移动： - 抓取开始时记录初始屏幕坐标 `p0`。 -
记录对象初始世界位置 `o0`。 - 后续指针位置为 `p(t)`。 -
将屏幕位移通过相机平面映射为世界位移 `deltaWorld(t)`。 - 对象位置
`o(t)=o0+deltaWorld(t)`。 - 地面约束开启时，对象最低点不得低于地面平面。

初始限制： -
单次抓取最大屏幕位移不限制，但对象必须保持在可恢复视野内。 -
若对象超出工作空间边界，显示边界提示，不得静默丢失。 -
对象移动跟随误差以对象投影中心与目标位置比较。

### 5.4 释放与提交

-   pinchClosure ≤0.48 连续 3 个有效结果，触发 Release。
-   结束当前抓取。
-   提交一次 transform 更新。
-   产生一个 Undo Step。
-   显示"已移动"反馈。
-   不允许释放后对象继续跟随。

### 5.5 量化指标

  指标                     初始目标 测试
  ---------------- ---------------- --------------------------
  抓取启动成功率            ≥95/100 标准对象抓取
  释放成功率                100/100 连续释放循环
  错误对象抓取               ≤1/100 相邻对象和重叠对象
  拖动终点误差       ≤视口对角线 2% 预设目标点
  跟随延迟               P95 ≤100ms 输入时间戳到对象渲染更新
  释放后残留运动               0 次 松手后静止观察 2 秒
  追踪丢失失控                 0 次 抓取过程中遮挡/断开

## 6. 局部按压凹陷

### 6.1 用户目标

用户指向模型表面并捏合，屏幕中命中位置周围的模型表面产生连续、局部、可控的凹陷。

### 6.2 参数

  参数                     V1 初始值 说明
  ---------------------- ----------- ---------------------------
  PRESS_START                   0.62 捏合启动阈值
  PRESS_RELEASE                 0.48 捏合释放阈值
  CONFIRM_FRAMES                   3 连续确认帧数
  LOST_TIMEOUT                 450ms 追踪丢失超时
  Brush radius default         0.10D D 为对象包围盒对角线
  Brush radius min             0.05D 最小影响半径
  Brush radius max             0.20D 最大影响半径
  Max dent depth            0.05Smin Smin 为对象最小包围盒尺寸

当前 Inventory 中雕刻半径 0.04---0.5、强度 0.2---2.5 属于现有
UI/实现参数。产品规格需要明确场景单位和对象尺度的关系；若保留原数值，必须提供尺度换算，不能直接对所有大小模型使用同一绝对半径而不验证效果。

### 6.3 强度映射

\[
S=clamp`\left`{=tex}(`\frac{pinchClosure-0.62}{1-0.62}`{=tex},0,1`\right`{=tex})
\]

\[ H=0.05`\times `{=tex}S\_{min}`\times `{=tex}S \]

S 为虚拟按压强度，H 为目标凹陷深度。

### 6.4 衰减

令 r 为顶点到接触中心的表面距离，R 为笔刷半径：

\[ w(r)=
```{=tex}
\begin{cases}
(1-r/R)^2,&0\le r\le R\\
0,&r>R
\end{cases}
```
\]

\[ `\Delta `{=tex}p_i=-n_i`\times `{=tex}H`\times `{=tex}w(r) \]

其中 `n_i`
为顶点法线。实际实现可以使用经过验证的等价平滑函数，但必须满足中心最大、边界归零、边界外不变。

### 6.5 防止累积漂移

-   每次操作保存开始前的几何基准。
-   每次更新根据当前强度和当前位置重新计算本次操作结果。
-   手部静止且强度不变时，形变不得持续增加。
-   不得逐帧把完整形变重复叠加到上一帧结果。
-   一次连续按压结束只生成一个历史步骤。

### 6.6 几何质量

-   所有顶点坐标必须是有限数值。
-   影响半径外顶点位移 ≤对象最小尺寸的 0.1%。
-   最大凹陷深度误差 ≤±10%。
-   实际影响半径误差 ≤±10%。
-   标准测试模型不得出现三角面翻转。
-   相同录制输入回放 10 次，最终形变 RMS 差异 ≤对象最小尺寸的 0.5%。

### 6.7 交互反馈

  状态             反馈
  ---------------- ------------------------------
  Hover            当前对象局部高亮
  PressCandidate   接触点显示待确认
  Pressing         显示笔刷范围、强度和预计深度
  Release          停止变形并提交
  Lost             冻结变形并提示追踪中断
  Unsupported      说明对象不支持雕刻

### 6.8 验收

  指标                                    初始目标
  ----------------------- ------------------------
  按压启动正确率                           ≥95/100
  释放正确率                               100/100
  空闲误启动                         ≤1 次/10 分钟
  凹陷深度误差                               ≤±10%
  笔刷半径误差                               ≤±10%
  端到端形变反馈            P95 ≤100ms，P99 ≤150ms
  静止保持 1 秒深度漂移           ≤最大深度的 0.5%
  连续操作卡死                               0/100
  非目标对象修改                              0 次

## 7. 局部拉伸

### 7.1 用户目标

用户抓住模型表面一点并向外拉，模型在抓取点周围产生连续局部形变，而不是整个模型整体移动。

### 7.2 启动条件

-   当前雕刻模式为"拖动拉伸"。
-   射线命中支持形变的 Mesh。
-   对象未锁定。
-   捏合达到启动阈值。
-   连续 3 帧命中同一对象。
-   当前无其他形变操作。

### 7.3 输入与计算

记录： - 起始接触点 `p0`。 - 当前接触点 `p(t)`。 - 起始表面法线 `n0`。 -
笔刷半径 R。 - 当前对象几何基准。 - 当前拖动向量 `d=p(t)-p0`。

将 d
投影到允许的形变平面，得到局部位移向量。对影响半径内顶点按衰减权重施加位移。

初始衰减：

\[ w(r)=(1-r/R)\^2 \]

\[ `\Delta `{=tex}p_i=d`\times `{=tex}w(r) \]

必须在实际网格上验证该方法不会造成明显的局部折叠、翻面或不连续。若出现网格质量问题，应采用更适合的局部变形算法，而不是简单扩大影响半径掩盖。

### 7.4 参数

  参数                                             初始值
  ------------------ ------------------------------------
  影响半径                                          0.10D
  最小半径                                          0.05D
  最大半径                                          0.20D
  单次操作最大位移                                  0.15D
  输入位移滤波         与指针滤波共享配置，但允许独立调整
  丢失超时                                          450ms

### 7.5 验收

  指标                               初始目标
  -------------------- ----------------------
  拉伸方向正确率                      ≥95/100
  目标位移误差                            ≤5%
  影响区域外位移         ≤对象最小尺寸的 0.1%
  端到端反馈                       P95 ≤120ms
  非有限顶点                                0
  标准测试网格面翻转                        0
  释放后残留运动                            0
  撤销恢复                               100%

测试模型必须包括球体、立方体、薄壁模型和高曲率区域。薄壁与高曲率模型应单独报告，不得混入平均值。

## 8. 双手缩放与旋转

### 8.1 启动条件

-   两只手都处于有效追踪状态。
-   用户已选中一个可变换对象。
-   两手均进入捏合状态。
-   两手身份稳定。
-   当前 UI 未消费手势。

### 8.2 缩放

记录双手初始间距 d0 和当前间距 d1：

\[ scaleFactor=d1/d0 \]

初始范围沿用当前实现： - 最小缩放 0.25×。 - 最大缩放 4×。

要求： - 采用统一缩放，保持 XYZ 比例一致。 - 达到边界后限幅。 -
双手距离短暂抖动不得造成比例跳变。 - 其中一只手丢失时冻结当前变换并进入
Lost 状态。

### 8.3 旋转

根据双手连线在屏幕平面中的角度差计算旋转增量。V1 当前仅定义绕 Y 轴旋转。

必须明确： - 角度方向。 - 角度零点。 - 跨越 ±π 时的连续性。 -
旋转中心。 - 旋转与缩放同时发生时的处理顺序。

### 8.4 验收

  指标                                       初始目标
  ----------------------------- ---------------------
  缩放比例误差                                    ≤5%
  旋转角度误差                                    ≤5°
  稳定双手状态 5 秒的比例漂移                     ≤1%
  单手丢失后无限缩放                             0 次
  无选中对象误操作                               0 次
  双手身份交换导致变换反转        0 次/100 次交叉测试

## 9. 取消、释放、撤销与异常

### 9.1 取消

-   Escape 或屏幕取消按钮可取消当前连续操作。
-   取消必须回滚到操作开始前状态。
-   取消不产生 Undo Step。
-   100 次取消测试，操作前后几何数据差异不得超过定义的浮点容差。

### 9.2 追踪丢失

-   第一帧丢失即冻结更新。
-   200ms 内恢复可在条件满足时继续。
-   超过 450ms 自动结束或回滚，具体按操作风险定义。
-   自动结束后不得自动重新启动操作。

### 9.3 对象状态变化

  情况             处理
  ---------------- ----------------------------
  对象被锁定       拒绝开始；进行中则安全结束
  对象被隐藏       拒绝开始
  对象被删除       立即终止，不再写入
  对象类型不支持   提示原因，不修改
  工具切换         先结束当前操作，再切换
  UI 抢占输入      不允许 3D 操作继续
  场景切换         当前操作必须先提交或回滚

## 10. 人体工学与用户测试

首轮探索性测试： - 8---12 名参与者。 - 每人完成 5 次抓取移动、5
次凹陷、5 次拉伸、5 次双手变换。 - 先提供不超过 3 分钟的统一教学。 -
记录首次成功率、完成时间、误操作、求助次数和疲劳评分。

评分： - 1：无法理解或无法完成。 - 2：多次失败，需要大量帮助。 -
3：能够完成，但不稳定或不自然。 - 4：基本自然，少量错误可自行恢复。 -
5：直觉明确、稳定、舒适。

初始目标： - 80% 参与者在教学后独立完成基础抓取和形变任务。 -
操作理解度平均 ≥4/5。 - 舒适度平均 ≥4/5。 - 任何评分为 1
的问题必须单独调查，不得用平均分掩盖。
